# 琉光表情角色素材库

应用按「应用更新」设置的 GitHub 或 Gitee 来源读取 `index.json`。发布新角色无需重新打包 APK：将三视图保存为 WebP，与索引放在同一个目录，使用 ASCII 文件名，再提交到两个仓库的 `main`。

`schema` 固定为 `1`。`characters` 是数组，每项包括唯一的 `id`（小写英文、数字、连字符）、角色 `name`、中文 `description`、图像 `width`、`height`、文件名 `file`、字节数 `bytes` 和小写十六进制 `sha256`。更换素材后须更新尺寸、字节数和 SHA-256。下载后素材保存在手机，用户可离线使用和重新排序。上传前检查只包含允许公开的角色素材。
