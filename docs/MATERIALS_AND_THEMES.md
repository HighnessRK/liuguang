# 材质、主题与图标

材质选择采用“大类 → 小类 → 预览 → 应用”。光透 8 种、毛绒 6 种、金属 5 种、自然 5 种、软塑 4 种、织物 4 种，共 32 种。材质只作为独立偏好段落追加，输入框内的原提示词不改写，明确要求冲突时仍以原提示词为准。预览是材质示意，不能保证模型生成效果逐像素一致。

参考了 [awesome-gpt-image-2](https://github.com/YouMind-OpenLab/awesome-gpt-image-2) 的图文预览浏览方式，以及 [StylePile](https://github.com/some9000/StylePile) 的风格组合思路。没有复制两项目的代码、提示词条目或预览图片。描述为原创，预览由 `tools/generate_material_assets.py` 本地程序绘制，无需任何模型 Key。参考仓库分别声明 CC BY 4.0、GPL-3.0，未将它们的素材或实现作为应用依赖。

八套主题各有四个背景渐变色与独立强调色。选择主题会更新整页极光背景、分段、按钮、滑条、选中状态，兼容深浅模式。主题预览为当前模式的缩略示意。玻璃不透明度与柔化滑条作用于实际卡片材质。

图标由 `tools/generate_launcher_icons.py` 绘制，4 种几何造型 × 6 种颜色 × 4 种材质，共 96 个原生自适应图标。Android activity-alias 切换不卸载应用、不替换包名；Android 13+ 使用批量组件状态切换。所有组合的 Android 资源均在构建时生成，页面预览读取实际原生图标。系统桌面可能延迟刷新；原始图标可随时恢复。

背景渐变、材质预览和图标资源均不需要联网。两组 API Key 的保存方式保持 Android Keystore 加密存储，不参与图标或主题生成。

## V1.0.3 图标更新

当前界面改为经典图标与八款完整渐变轨道设计，不再拆分造型、颜色和材质。成品图标由 tools/generate_curated_icons.py 绘制，配色来自主题氛围。旧 96 个 alias 保留以兼容历史选择；重新生成时先运行旧生成器，再运行成品生成器。外观入口位于个性化页。
