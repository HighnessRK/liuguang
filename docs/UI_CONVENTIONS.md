# 界面约定

采用系统字体与 Flutter_miuix 主题语义色。主页面标题、二级标题、正文、辅助文字依次使用 28/20/16/12–14；状态卡标题为 16，避免同一区域出现多种强调字号。浅色和深色均从当前主题取文字、表面与强调色。

输入统一通过 `GlassField` → `StudioEditable`。不得直接使用叠放的提示文字，或重新引入 MiuixTextField 的独立占位层。提示由 InputDecoration 根据真实编辑值绘制，必须同时检查键盘预编辑、粘贴、清空和程序赋值。

可选择文本统一使用 `StudioSelectable`，编辑菜单统一由 `studioEditingMenu` 提供。只显示当前可用的剪切、复制、粘贴、全选；不使用 Android 原生扩展操作栏。

按钮使用公共 Glass 表面与 Flutter_miuix 语义色；分段、滑条、复选框和开关通过公共组件使用 Flutter_miuix。分段项不添加独立灰色描边。卡片使用共享背景模糊，导航保持独立透镜；不添加定时截图刷新。

异步任务使用 `TaskStatusCard`。任务运行时替换原控制区，锁定所有重复提交和会改变图片的入口，单独显示阶段、真实耗时与取消。没有服务端进度时使用不定进度，不能伪造百分比。

生成与导出保留实际像素，服务端未遵循比例时明确提示，不能用拉伸或裁切伪装请求成功。长按删除保留确认，不在作品列表放常驻操作教学。

发布前运行 `dart analyze lib test integration_test` 和 `flutter test --no-pub`。测试覆盖 390×844、深浅主题、额外字号、IME 占位提示、中文编辑菜单、任务锁定与取消、更新弹窗与日志去重。真机验证和纯桌面测试必须分别记录。

卡片高度由内容决定，不给普通信息卡或按钮设置无意义的固定高度。列表行只保留一层纵向内边距，卡片内边距与行内边距避免重复叠加。长列表可使用有上限的视口，短列表根据内容收紧；图片、可视化和滑动预览可按内容比例保留高度。

次要操作使用内容宽度并居中；主要提交按钮保留充足点击区域。修图工具图标与文字在按钮内部居中，整排不足一屏时居中，字号增大时允许横向滚动。返回与关闭按钮使用共享液态玻璃实现。

个性化首页只提供并列的外观和桌面图标入口；图标页直接显示成品卡片，卡片右下角勾选，不加入独立的大图预览。

打开图片后提供关闭入口，未导出的像素调整、选区和进行中的 AI 任务离开前确认。关闭会取消请求并重建编辑器，阻止旧任务重新填入图片；不删除原图或已保存作品。

PopupRoute（弹层、对话框）中的操作按钮不创建独立液态玻璃捕获层：路由平移动画与独立捕获叠加会出现只有面板、按钮空白的情况。使用相同主题的磨砂玻璃分支，必须验证弹层中的内容可见且点击有效；长按作品只进入页面内多选，不再打开菜单。不能仅凭无异常日志判定通过。

作品分享图必须用本地绘图模板，不得以识图或生图替代排版。需要可见的本地生成状态，渲染错误有提示，生成不会增加模型用量。


页面空间统一：外边距 24，区块标题上 24 / 下 12，同组操作间距 8–12，批量栏到作品网格至少 20。控件按内容收紧，长说明使用 12–14 字号和明确行高。窄屏 / 放大字号时允许换行；时间轴减少刻度，不能让字挤出卡片。

长按作品直接进入多选，不弹操作菜单。分享图与全选、取消、删除所选同级。创作的相册 / 作品来源仅在添加底图或参考图时出现；模型连接使用生图 / 对话 / 识图三个并列标签。

真实玻璃共用 StudioBackground 的页面级 LiquidGlassCapture 坐标范围；不能在多个小范围 Capture 之间共用同一个 BackdropKey，否则长按钮会裁断。按钮内容位于效果背景之上。导航底板和选中透镜重叠，分别使用 BackdropGroup；弹窗动画仍采用稳定磨砂分支。

AI GIF 入口直接进入原生创作；模型不属于允许系列时说明暂不支持。有图片时可不输入提示词，由识图分析动态描述，用户补充要求优先。不能展示对原生 GIF 未生效的本地调色精度控件。


半透明主按钮不得直接使用实色 primary 的 onPrimary。使用玻璃前景对比规则，文字、图标、忙碌指示必须一致；编辑选中工具与用户对话气泡也使用同规则。禁用状态保持可辨认，浅 / 深色及增强对比均需检查。

页面进出可短时复用 Flutter 页面纹理，完成 / 取消即释放，页面内玻璃仍实时采样；不能常驻整页截图或定时刷新。平台视图不支持缓存时直接绘制。减少动态效果时不使用进出场动画，停止呼吸星光计时。

作品选中标记使用绿色底、白色勾和描边，保证明暗照片上都清楚。长按尊重触感开关；操作栏展开 / 收起有高度与透明度过渡，收起时不可触发其中按钮，关闭动态效果时即时切换。

版本说明须覆盖已实现的用户可见功能与修复，应用内日志和 CHANGELOG 同步；合并同类条目不能丢失入口、限制和行为变化。不写实现承诺、假进度或未经验证的厂商认证。
