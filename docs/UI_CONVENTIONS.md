# 界面约定

采用系统字体与 Flutter_miuix 主题语义色。主页面标题、二级标题、正文、辅助文字依次使用 28/20/16/12–14；状态卡标题为 16，避免同一区域出现多种强调字号。浅色和深色均从当前主题取文字、表面与强调色。

输入统一通过 `GlassField` → `StudioEditable`。不得直接使用叠放的提示文字，或重新引入 MiuixTextField 的独立占位层。提示由 InputDecoration 根据真实编辑值绘制，必须同时检查键盘预编辑、粘贴、清空和程序赋值。

可选择文本统一使用 `StudioSelectable`，编辑菜单统一由 `studioEditingMenu` 提供。只显示当前可用的剪切、复制、粘贴、全选；不使用 Android 原生扩展操作栏。

按钮、分段、滑条、复选框和开关通过公共 Glass 组件使用 Flutter_miuix。分段项不添加独立灰色描边。卡片使用共享背景模糊，导航保持独立透镜；不添加定时截图刷新。

异步任务使用 `TaskStatusCard`。任务运行时替换原控制区，锁定所有重复提交和会改变图片的入口，单独显示阶段、真实耗时与取消。没有服务端进度时使用不定进度，不能伪造百分比。

生成与导出保留实际像素，服务端未遵循比例时明确提示，不能用拉伸或裁切伪装请求成功。长按删除保留确认，不在作品列表放常驻操作教学。

发布前运行 `dart analyze lib test integration_test` 和 `flutter test --no-pub`。测试覆盖 390×844、深浅主题、额外字号、IME 占位提示、中文编辑菜单、任务锁定与取消、更新弹窗与日志去重。真机验证和纯桌面测试必须分别记录。
