### 随想真实模型复测

- 用户补充生图配置后，按最多三次提交执行。第 1 次通过正式版提交，在 TCP 连接阶段 25 秒超时，未返回图片；不自动重试。手机 curl 对相同 HTTPS 地址也连接超时，对其他网站则可成功。
- 为隔离网络因素，临时使用 `adb reverse` 和电脑 HTTP CONNECT 代理，手机端保持默认 TLS 证书校验，Key 仍只由手机安全存储读取，不复制到电脑。只对测试代码启用此通路，正式版和已保存 API 地址未修改。
- 第 2、3 次由 `--no-uninstall` 的 live-only 集成测试执行。请求拦截器将本轮剩余图片 POST 硬限制为两次，轮询与结果下载不创建新任务。日志恰好两条 `LIVE_PROVIDER_SUBMIT`，测试通过，全程没有额外重试。
- 实际配置为 GPT Image 协议、`gpt-image-2.6-sunburst`。竖幅请求 768×1024，实际返回 **1086×1448（精确 3:4）**；原图像素保留，未旋转、裁切或拉伸。模型没有精确遵循所请求像素，不能将请求的 K 档当作实际返回像素。
- 景深请求使用内置示例构造的 7680×4320 PNG，经同一上传预处理生成合规副本，实际返回 **1672×941**；未出现 Invalid image data。已检查结果画面可见远景虚化和影调变化。生成式增强会改动细节，不是专有光学算法或像素无损处理。
- 竖幅样例未完整呈现提示中的小木屋，因此本次证明比例和编辑通路可用，不将其视为模型完全遵循所有画面内容的证明。
- 两张结果留在手机作品页。已通过保留数据的覆盖安装恢复发布的正式包，移除 USB 转发，并恢复 Wi-Fi 关闭状态。手机当前网络直连接口仍不可用，本次成功不能作为手机独立直连网络可用的证明。总提交数按保守口径为三次，不再调用模型。
