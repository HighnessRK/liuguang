# V1.0.0 验证记录

日期：2026-11-09，Asia/Shanghai。

## 自动验证

- `dart analyze lib test integration_test` 静态检查。
- `flutter test --no-pub`：16 项测试，覆盖原提示词、地址归一化、配置不包含 Key、保持 HSL 明度、裁切/旋转尺寸、选区外逐像素保护、GIF 帧数与帧时长。
- 本机真实 HTTP 模拟服务验证完整模型列表、JSON 生成、多图 multipart 和 mask、两组 Authorization、下载不带 Key、Token 计价、401 和取消无重试。
- 390×844 窗口，浅色/深色及 120% 额外字号下，四个主页面与连接设置的导航和布局检查。
- 导航尺寸为 288.6×60（390 宽窗口），横向拖动可切换设置；设置根页只展示分类，外观详情在二级页面。

## USB 真机

小米 23127PN0CC，Android 16 / API 36 / ARM64。

`integration_test/device_test.dart` 在手机启动隔离的本地 HTTP 服务，使用临时目录和独立加密探针，结束后清理；不会写入用户的两组 API 配置。

- Android Keystore 加密读写。
- 模型发现、文生图、多图+蒙版、对话润色的 HTTP 通路。
- 原生 WebP 编码、GIF 双帧编码、MediaStore 相册保存。
- Flutter GPU 实时玻璃、调色 shader、默认保持明度。已移除 Compose PlatformView 与截图回传。
- 玻璃导航点选和横向拖动；编辑器照片固定、工具区独立滚动，预览位置保持不变。
- 按钮留白与中心可点击，导出面板可以正常打开并保存。
- 色彩平衡调整后按原始尺寸导出、作品索引与相册保存。

测试会在系统相册留下几张程序生成的小尺寸色块，便于确认保存链路；不会修改已有相册照片。

## 真实服务商

用户选择自行填入地址和 Key，未消费商业模型额度。服务商权限、非标准参数、实际审核、生成质量、真实景深效果与实际扣费尚未验证。应用展示实际响应错误，不伪造生成图片、Token 或费用。

## 发布检查

最终 APK 和校验值位于 `dist`，真机截图位于 `docs/screenshots/final-*.png`。

修订版正式包已在同机安装验证。浅色和深色下检查了设置分类、二级外观、编辑器、保持明度和导出面板；编辑器滚动工具区不会越界遮盖固定预览。PNG/JPEG 导出格式、压缩滑块、复选框和保存按钮均可见、可用。弹出面板使用独立的内层玻璃层，修复区域捕获导致子控件消失的问题。保存提示移至导航上方。

桌面测试和真机集成测试已通过，商业 API 仍未填写。APK 仅包含 Flutter 裁剪后的图标字形资源，未打包或安装额外文字字体。

最终交付：ARM64 正式签名包，22,330,468 字节（约 21.3 MiB），V1.0.0。APK v2 签名验证通过，设备已安装 APK 的 SHA-256 与 `dist` 交付文件一致。最后一轮真机导出得到 1600×1067 的副本并写入相册，提示显示在导航上方，随后可切换作品页。

在同机 Profile 模式连续拖动、切换导航时，预热后采样的一组 120 帧构建耗时 p90 为 2.413 ms、光栅化 p90 为 8.56 ms。这是该设备和测试场景的采样结果，不代表所有设备或所有操作的帧率保证。
